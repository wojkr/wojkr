## ⚙️ How I build

- **Clear structure first.** OOP, SOLID, and design patterns where they remove complexity, not where they add it.
- **Tested code.** Unit tests with xUnit and NUnit; APIs checked with Postman and Swagger.
- **Fast, accessible front ends.** Semantic HTML, keyboard support, and small bundles.
- **Readable history.** Small commits, clear messages, reviewable pull requests.
